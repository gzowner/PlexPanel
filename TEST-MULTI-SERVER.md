# Multi-server Test

1. Register two independently owned Plex servers.
2. Sync both library inventories.
3. Confirm libraries remain grouped by their server.
4. Assign a test account to one library on each server.
5. Synchronize access and verify each server receives only its selected libraries.
6. Start playback on both servers and confirm Stream Operations shows both sessions.
7. Scan a library on Server A and confirm no scan command is sent to Server B.
8. Disable Server B and confirm Server A remains usable.
9. Delete Server B and verify Server A, its customers, and history remain intact.
